# Zeedas Project Management Tool

## Overview

A REST API backend for a software development management platform built with Node.js and MongoDB. My first professional project as a junior developer, where I contributed to building project management features and implemented advanced MongoDB search functionality.

## Key Features

- **Project Management API**: RESTful endpoints for managing software development projects
- **Advanced Search**: MongoDB text search implementation for efficient data retrieval
- **Team Collaboration**: Features supporting multi-developer workflows
- **NoSQL Architecture**: Flexible MongoDB data storage for project management data
