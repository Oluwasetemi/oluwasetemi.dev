# SecLot Security Services Platform

## Overview

A platform democratizing access to security services across Nigeria. Built during my time at Natterbase, SecLot connects individuals and businesses with verified security service providers through a modern web and mobile interface.

## Key Features

- **Security Service Marketplace**: Platform connecting users with verified security providers
- **Service Booking**: Real-time booking and scheduling of security services
- **Provider Management**: Verification and management system for security service providers
- **Mobile-First Design**: Responsive interface optimized for Nigerian mobile users

## My Role & Responsibilities

- Contributed to full-stack development as part of Natterbase engineering team
- Built React components with Redux for complex state management
- Developed RESTful API endpoints with Node.js and Express
- Implemented MongoDB data layer with Mongoose ODM
- Collaborated on feature development and deployment

## Technical Highlights

Worked on a platform addressing critical security needs in the Nigerian market. The REST API architecture provided reliable communication between web and mobile clients. Redux state management handled complex booking workflows and real-time service provider availability. MongoDB with Mongoose offered flexible data modeling for diverse security service types and provider profiles.

## Impact & Results

- **Social Impact**: Improved access to security services across Nigeria
- **Full-Stack Contribution**: Developed both frontend and backend features
- **Professional Growth**: Enhanced skills in production web development
- **Team Experience**: Collaborated effectively in professional environment
