# ACA Investment Platform

## Overview

An investment platform facilitating connections between African startups and investors. Built during my time at Natterbase, this platform leverages modern web technologies to create a seamless investment experience for the African market.

## Key Features

- **Investment Marketplace**: Platform connecting startups with potential investors
- **GraphQL API**: Modern data fetching with GraphQL for efficient client-server communication
- **User Management**: Separate interfaces for startups and investors
- **Data Visualization**: Investment analytics and startup metrics dashboards

## My Role & Responsibilities

- Contributed to full-stack development as part of Natterbase engineering team
- Implemented React components with Redux state management
- Developed GraphQL API endpoints with Node.js backend
- Worked with MongoDB for data persistence and querying
- Collaborated with cross-functional team on feature development

## Technical Highlights

Worked on a production platform serving the African investment ecosystem. The GraphQL implementation provided flexible data querying for complex investment data relationships. Used Redux for managing application state across multiple user types and workflows. Contributed to both frontend and backend features, demonstrating full-stack capabilities in a professional environment.
