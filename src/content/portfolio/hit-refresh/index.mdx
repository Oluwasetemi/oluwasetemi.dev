# Hit Refresh - Event Platform

Professional event management platform for the Career + Wellness Summit 2026 in Lagos, Nigeria. A comprehensive solution for ticket sales, sponsorship management, and event information.

## Overview

Built specifically for the Career + Wellness Summit, this platform handles all aspects of event registration and management, from individual ticket purchases to corporate sponsorships.

## Key Features

- **Multi-Tier Ticket Purchasing**: Four distinct ticket types catering to different attendee needs
  - **General Admission**: Standard access to all summit activities
  - **VIP Tickets**: Premium seating, exclusive networking, and special perks
  - **Corporate Packages**: Group discounts for company teams
  - **Virtual Attendance**: Remote participation option for global audience
- **Sponsorship Management**: Dedicated portal for event sponsors and partners
- **Event Information Hub**: Comprehensive details about speakers, schedule, and venue
- **Payment Processing Integration**: Secure payment handling with multiple payment methods
- **Attendee Dashboard**: Post-purchase access to event materials and updates

## Event Details

**Career + Wellness Summit 2026** is a professional development event focused on balancing career growth with personal wellness, featuring:

- Industry leaders and keynote speakers
- Interactive workshops and breakout sessions
- Networking opportunities with professionals across industries
- Wellness activities and mindfulness sessions
- Career coaching and mentorship opportunities

## Technical Implementation

Built with React and TypeScript, featuring seamless payment integration and responsive design for optimal user experience.

### Core Technologies

- **Frontend**: React with TypeScript for type-safe component development
- **Payment Integration**: Secure payment gateway integration (Paystack/Flutterwave)
- **Event Management**: Custom ticketing and registration system
- **Email Automation**: Automated ticket delivery and event reminders
- **Deployment**: Vercel for reliable, scalable hosting
